**Что действительно выполнено**

- Этап 9: два MLP-продолжения старых весов, direct и trace, по 1200 шагов.
  18000 новых русских миров + повторение прежних задач. Лучший средний dev
  36.46% против 17.50% до обучения; порог 50% не пройден. Большая сетка
  не запускалась. Лучшие/последние веса, все dev-ответы, код и данные сохранены.
- Этап 10: один MLP-пилот перевода предложений, 1200 шагов, 38400 предъявлений
  из 26738 уникальных предложений, извлечённых из train этапа 9.
  Сегментация предложений и соединение переводов заданы интерфейсом.
  Правильных состояний памяти или программного русского парсера при выводе нет.
- Целая программа переведена точно в 98.75% обычного dev, но только в 8.33%
  dev_phrases. Точность отдельных предложений новых форм — 64.30%.
  Порог подтверждения (80% предложений и 50% программ) не пройден.
  Графовые подтверждения и три seed не запускались. Это открытые пилоты.
- Конвейер «переводчик + фиксированный history_seed1» решает 51.67% обычного dev
  и 41.25% новых форм. С правильной программой тот же исполнитель даёт 52.08%.
  Контроль с правильной программой существует только в диагностике.
- В новых формах копирования неверны все 309 переводов: 151 запись цифры,
  153 выхода другого формата, 5 копирований с неверными аргументами. Исходные ответы
  и первые ошибки в фиксированном порядке: results/stage10_russian/diagnosis/.
- Тесты этапов 9/10 не открывались; test_open.json нет. Их входы/метки созданы
  и проверены программно, но метрики моделей на них не вычислялись.
- Проверены хеши, сохранённые предсказания, причинность, начальное сохранение
  функции и работа inference при заблокированных импортах учителей.

**Рабочий интерфейс**

```bash
python fly_russian_pipeline.py 'Дано: a=два, b=семь, c=ноль, d=один. Перепиши значение b в a. Не меняй значение a. Чему равно a?' --json
python stage9_russian_experiment.py verify
python stage10_russian_experiment.py verify
python stage9_russian_audit.py
python stage10_russian_audit.py
python stage9_russian_report.py
python stage10_russian_report.py
```

Русский default — пилот, выбранный по dev, не независимо подтверждённая модель.
Демо выше переводится в корректную программу, нейронный исполнитель отвечает 7.
Это один проверенный пример, не оценка общей надёжности.
Основной default этапа 7 остаётся history_seed1; старый fly_memory.py не изменён.
Языковой модуль — отдельная копия сети; сохранение старых навыков обеспечено
раздельными весами, не продемонстрированным непрерывным обучением одной модели.

**Следующий опыт**

Следовать notes/RUSSIAN_NEXT_STEPS.md. Не расширять неудачные пилоты задним числом.
Сначала зафиксировать новый протокол по выявленным ошибкам. Обучать различение
источника/получателя при изменении порядка слов; отдельно чинить нейронное
исполнение с правильным формальным входом. Данные dev уже открыты и годятся
для разработки, а не независимого подтверждения.
Сначала короткий пилот с содержательным порогом, затем минимум три seed и
контроли по заранее заданному бюджету. Новые тесты — до подтверждения; после
их открытия никакой подстройки. Масштабирование числа нейронов — отдельный опыт.
