## Главный результат этапа 5

Система memory/fly при 32 демонстрациях даёт 100% правильных ответов на XOR
двух битов и около 99,33% на чётности трёх. Это точность отдельных вопросов;
доля полностью правильных 32-вопросных эпизодов ниже — см. отчёт.
Память ограничена подмножествами до трёх существенных координат. На чётности
четырёх битов — около 46%, что показывает отсутствие общего алгоритма чётности.

В отдельном активном опыте на 64 новых правилах seed 0 memory/fly получает
100% ответов после 16 выбранных примеров против 89,45% при случайном выборе.
При восьми примерах активный вариант хуже случайного. Это не доказательство
универсального выигрыша активного обучения; политика вопросов написана нами.

Перебор координат, группировка демонстраций, статистики и извлечение меток
из памяти даны программно. Нейросеть учит оценку полезности каждой части
памяти; новый контекст меняет поведение без изменения весов. Написанный
Occam baseline сопоставим или лучше. Особого преимущества исходного
коннектома перед обычными сетями и алгоритмами не установлено.

## Запуск

```bash
python restore_large_files.py
python fly_rules.py --examples-file data/stage5/demo.json --suggest
python fly_rules.py --examples '00000000=0;10000000=1;01000000=1;11000000=0' --query '10100000;01100000' --suggest
python fly_program.py --data '1 2 3' --goal '4 3 2'
python smart_fly.py 'сложи 99999999999999999999 1' --verify
```

Default checkpoint: results/stage5/confirmation/memory_fly_seed0/best.pt.
Формат входов — биты, не свободный русский язык. --suggest предлагает вход;
его метку должен дать человек. Ничего не дообучается в фоне.
Флаг forced — отдельная проверка согласия всех непротиворечивых правил
в заданном классе. Вероятность сети и этот условный флаг не являются
безусловной гарантией правильного ответа.

## Воспроизведение

```bash
python stage5_train.py --mode memory --conditions fly --seeds 0 --steps 6000 --eval-every 1000 --output results/stage5/reproduction
python stage5_report.py
```

Установленные версии зависимостей перечислены в requirements.txt. Большой
исходный Connectivity_783.parquet хранится побайтно в assets/connectivity_783;
restore_large_files.py проверяет и восстанавливает его без внешней сети.
Новые данные этапа 5 лежат обычными файлами, заново генерировать их не нужно.

Для --resume сначала скопируйте каталог с best.pt и last.pt, затем передайте
путь копии и увеличьте общее --steps. Восстанавливаются optimizer и RNG,
но cosine-расписание пересчитывается. Проверка 600→601 проведена на копии,
оригинал неизменён: results/stage5/resume_verification.json.

Все финальные тесты этапов 1–5 уже открыты. Не подбирать новые настройки
по ним и не объявлять повторение независимым испытанием. Исходники, данные
и список моделей до открытия зафиксированы в confirmation/plan.json;
best/last до теста — в results/stage5/checkpoints_before_test.json.

## Следующие содержательные задачи

1. Учить построение представления или расширение класса гипотез. Сейчас
   сильное предположение «не более трёх бинарных координат» задаёт человек;
   просто увеличить перебор до четырёх — инженерное расширение, не выученное
   изобретение нового способа рассуждения.
2. Учить политику вопросов и сравнить с текущей неопределённостью, случайным
   выбором и символическим поиском при одинаковом числе ответов среды.
   Новые семейства и окончательные тесты нужны до первого нового подбора.
3. Перейти к переменным, вложенным выражениям и действиям с памятью, которые
   нельзя решить небольшой таблицей истинности. Сохранить обычные нейросети
   и простые алгоритмы как обязательные контроли.
4. Проверять шум и смену правила во времени, забывание, стоимость поиска,
   калибровку уверенности. Текущая независимая память эпизодов не доказывает
   долговременного накопления знаний.
5. Испытать разные независимые фрагменты коннектома прежде, чем говорить
   о его полезности. Успех против обнулённых связей не означает превосходства
   над обычной архитектурой.

Арифметика, лента и новые правила остаются раздельными модулями. Не выдавать
совместный CLI или наличие файлов в одном репозитории за обучение широкому
интеллекту, понимание русской речи или произвольное программирование.
Все включённые запуски завершены; непрерывного фонового самообучения нет.
