**Проверка механизмов**

На фиксированных первых 120 тестах отключение чтения истории снижает среднюю точность группы history с 78.30% до 60.61%. У группы slots отключение ячеек снижает её с 82.17% до 79.58%. Это вмешательства после обучения, без повторного обучения контроля; они показывают зависимость готовых весов от компонентов в этих условиях.

В обычной генерации нет программного решателя и правильных состояний переменных. Четыре демонстрации CLI прошли при заблокированном импорте учителей; это проверка работоспособности, не оценка точности. Во всех вариантах остаётся доступ ко всему предыдущему тексту, поэтому сохранение данных после удаления контекста не проверялось.

В модели с исходным графом используются 256 узлов / 7514 связей, повторённые в трёх искусственных блоках. Большая часть архитектуры искусственная. Это не полная эмуляция мозга мухи. Свободный русский язык, создание произвольных программ и широкий интеллект здесь не продемонстрированы.

**Использование опубликованной модели**

```bash
python fly_memory.py 'код a=2;b=3;c=0;d=1;a=7;b=8;?a' --json
python fly_memory.py 'код a=2;b=3;c=0;d=1;a=(a+b)%10;b=(b+1)%10;?a' --json
```

При проверке эти примеры дали соответственно `a=7;b=8|7` и `a:2+3=5;b:3+1=4|5`. Ответы на другие входы могут быть ошибочными.
