# FlyBrain Lab — первый эксперимент

Это воспроизводимый исследовательский проект на основе настоящего коннектома
дрозофилы. Он не является полной цифровой копией животного. Обучение проведено
на структурном фрагменте графа; полные исходные данные сохранены отдельно.

## Что находится в проекте

- `data/raw/`: полный граф FlyWire v783 из репозитория Philip Shiu и список нейронов.
- `data/source_manifest.json`: закреплённый commit, источники, размеры и SHA-256.
- `upstream/`: неизменённый оригинальный код Brian2, описание и лицензия MIT.
- `prepare_graph.py`: проверка данных, распространение сигнала на полном графе
  в упрощённой модели, выбор связанного фрагмента без использования учебных заданий.
- `smoke_original.py`: короткий запуск полной исходной модели Brian2.
- `model.py`: обучаемые непрерывная (`rate`) и импульсная (`lif`) модели.
- `tasks.py`: генератор русских команд и простейших программ, разделение данных.
- `train.py`: обучение, проверка, контрольные сети, сохранение и продолжение обучения.
- `evaluate.py`: самостоятельная генерация ответов и проверка кода исполнением.
- `infer.py`: использование сохранённой сети из командной строки.
- `checks.py`: проверки графа, отсутствия утечки между выборками и градиентов.
- `RESULTS.md`: фактические результаты запуска; `CONTINUE.md`: дальнейшая работа.

## Запуск

Требуется Python 3.12. В архив не входит виртуальное окружение.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install torch==2.14.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python download.py
python prepare_graph.py --nodes 256
python checks.py
python infer.py 'сложи 3 4'
python infer.py --interactive
python infer.py 'код сложи a b' --checkpoint results/spiking/lif_fly_seed0/best.pt
```

В Windows активация окружения: `.venv\Scripts\activate`. CPU достаточно для
включённых небольших экспериментов; время на другой машине может отличаться.

Повторить основной опыт с новым каталогом результатов:

```bash
python train.py --cells rate --seeds 0,1,2 --conditions fly,rewired,frozen --epochs 40 --output results/reproduction_rate
python train.py --cells lif --seeds 0,1,2 --conditions fly,rewired,frozen --epochs 40 --output results/reproduction_lif
```

Продолжить один запуск, увеличив общее число эпох:

```bash
python train.py --resume results/main/rate_fly_seed0/last.pt --epochs 80
```

Сохраняются параметры модели и оптимизатора, состояния генераторов случайных
чисел, словарь, конфигурация и журнал. Для сравнения будущих подходов нужно
создать новую финальную проверочную выборку: результаты текущей уже просмотрены.

## Что именно моделируется

Полный источник содержит 138 639 нейронов, 15 091 983 направленных пар и
54 492 922 контакта, агрегированных по этим парам. Число пар и число отдельных
синапсов — разные величины. Проверено соответствие индексов исходным ID.

Первый обучаемый фрагмент содержит 256 нейронов и 7 514 направленных связей,
около 0,185% нейронов источника. Выбор: обход сильных соседних связей от нейрона
с максимальной суммарной исходящей абсолютной силой. Это выбор структуры для
дешёвого опыта, не случайная репрезентативная выборка и не выделенный речевой
центр. Связи с оставшейся частью мозга в обучаемый фрагмент не входят.

Сила каждой существующей связи обучается; её знак сохраняется. Параметризация:
`w = sign(source) * normalized_log1p(abs(source)) * exp(clamp(gain, -4, 4))`.
Начальная нормировка по входящим связям задаёт их L2-норму 0,65. Нулевые в
коннектоме связи остаются нулевыми. Для скорости небольшой граф умножается
как плотная матрица, но обучаемых рекуррентных параметров только 7 514.

`rate`: состояние обновляется как `0.25*h + 0.75*tanh(input + W*h)`.
`lif`: `u = 0.85*v + input + W*spikes`, импульс возникает при `u > 1`,
после него из потенциала вычитается 1. Обучение импульсов использует
приближённый градиент `1/(1+5*abs(u-1))²`. Выход читается из потенциалов.

Шаг равен одному текстовому токену, а не миллисекунде биологического времени.
Нет исходных временных задержек, рефрактерности, морфологии и полной биохимии.
Вход — искусственная обучаемая таблица токенов, выход — обучаемое линейное
преобразование в вероятности токенов. Между ними только состояние данной
рекуррентной сети; внешней языковой модели и готового решателя в ответах нет.
Вход и выход подключены ко всем выбранным нейронам, а не к биологическим
органам чувств. Поэтому результат относится к этой модифицированной системе.

Исходная модель Brian2 проверяется отдельно, без обучения. В обёртке удалено
обнуление необъявленной переменной `w` из строки reset исходного кода.
Сам файл источника не менялся. Это численная проверка запуска, а не повторение
экспериментов статьи и не проверка поведения животного.

## Задания и честная проверка

1. Арифметика: «сложи», «вычти», «максимум», «минимум» для двух цифр.
2. Память: повторить или развернуть последовательность из трёх цифр.
3. Код: вывести Python-функцию из небольшой грамматики сложения, вычитания,
   `min` и `max`, сохранив имена двух аргументов. Это шаблонная генерация кода,
   не создание новых алгоритмов или работа с реальным репозиторием.

Данные получены алгоритмически, из явно заданных правил. Словарь строится
только по обучающей выборке; числа разбиваются на отдельные цифры. При проверке
арифметики нет учебных пар чисел, даже в обратном порядке. Для памяти проверяются
новые последовательности; для кода — новые упорядоченные пары имён аргументов.
Отдельно проверяется новое сочетание уже знакомых слов в формулировке команды.

Три условия в каждой архитектуре и по три случайных инициализации:

- `fly`: обучаются существующие связи реального фрагмента и вход/выход.
- `rewired`: переставлены адресаты связей; входящая и исходящая степень
  каждого нейрона, число рёбер и число обучаемых параметров сохраняются.
  Сила прикреплена к исходящему ребру; распределение по получателям и нормировка
  могут измениться. Это контроль структуры, не всех возможных свойств сети.
- `frozen`: исходные рекуррентные связи фиксированы, обучаются только вход/выход.

Веса выбираются по средней точности трёх типов заданий на validation.
Тестируется самостоятельная генерация до `<eos>`, без подстановки верных
предыдущих ответов. Код дополнительно проверяется на пяти парах числовых
входов. Синтаксическая корректность и прохождение тестов отмечены отдельно.
Удаление всех рекуррентных связей после обучения — дополнительная абляция,
не отдельная обученная контрольная сеть. Одинаковые правила обучения во всех
трёх условиях; подбор параметров отдельно под каждую сеть не проводился.

Этого пилота недостаточно для вывода о преимуществе коннектома в целом:
исследован один фрагмент, три seed, небольшой искусственный язык и ограниченный
бюджет обучения. Аудио, свободный русский, новые алгоритмы, сознание и сходство
обучения с живой мухой здесь не проверяются.
