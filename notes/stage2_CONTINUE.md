Читайте `STAGE2_RESULTS.md`, `results/stage2/summary.json`, `README.md` и

его исходный план продолжения — в `notes/stage1_CONTINUE.md`.

## Что сделано

1. Скачаны и проверены полный граф v783, оригинальный Brian2 и лицензия.
2. Реализованы непрерывная и импульсная обучаемые сети на фрагменте 256 нейронов.
3. Выполнены 18 запусков первого протокола.
4. Диагностика показала запоминание учебного кода и слабое сохранение последовательностей.
5. Во втором этапе добавлены регулируемая динамика и искусственная память состояний
   входного запроса с обучаемым вниманием.
6. Новый набор содержит 11 952 учебных примера; финальные группы и длины выделены заранее.
7. После четырёх пробных запусков по validation выбрана `memory_rate`.
8. Подтверждение: старая архитектура, исходный/переставленный/фиксированный/отключённый
   коннектом и GRU близкого размера, по три seed, по 2 400 шагов.
9. Checkpoints, предсказания, журнал, строгая проверка аргументов функций сохранены.

## Как использовать

```bash
python infer.py 'повтори 1 2 3'
python infer.py 'код сложи u x' --json
python infer.py --interactive
python stage2_checks.py
```

Для продолжения обучения конкретного checkpoint:

```bash
python stage2_train.py --resume results/stage2/confirmation/memory_rate_fly_seed0/last.pt --steps 4000
```

Это меняет существующий запуск. Для нового исследования сначала скопируйте нужные
checkpoints в новый каталог. Расписание скорости адаптируется к новому общему
бюджету; предыдущие шаги не переигрываются. После изменения результатов заново
сохраните архив и отчёт, сохранив историю первого и второго протоколов.

## Что исследовать дальше

- Сначала изучить результаты всех контролей. Улучшение с искусственной памятью
  нельзя целиком приписывать биологической схеме. Особенно важен контроль,
  обученный с нулевыми рёбрами коннектома: он сохраняет вход/выход, внутреннее
  состояние отдельных элементов и внимание, но не эти межнейронные связи.
- Не менять настройки по уже открытому финальному тесту. Создать третий протокол
  с новыми тестовыми группами до подбора модели. В текущем тесте дополнительно
  проверены длины 6–7; их дальнейшее использование будет исследовательским,
  а не новой независимой оценкой.
- Разобрать оставшиеся ошибки отдельно: сложение, вычитание, повторение,
  разворот, цифры, имена, длина, строгое соблюдение сигнатуры функции.
- Проверить несколько структурных фрагментов, а не только сильных соседей
  одного узла. Любое изменение размера сравнивать с контрольными графами.
- Проверить память с меньшим числом сохранённых состояний и одинаковыми
  ограничениями во всех контролях: это поможет выяснить, когда граф становится
  полезен, вместо того чтобы расширять внешнюю память без измерений.
- Для более осмысленного программирования перейти от четырёх шаблонов к
  составным выражениям, условию и неизвестным комбинациям операций, с новым
  закрытым тестом на структуры программ. Сохранить отдельную проверку привязки
  имён и поведения.
- Работа со звуком и свободный русский пока не реализованы. Распознавание и
  озвучивание можно добавить как интерфейс, но это не будет свидетельством
  обучения слуховой системы коннектома.

## Технические ограничения

В `model.py` маленький граф материализуется как плотная матрица; такой путь не
подходит для всех 138 639 нейронов. Перед масштабированием нужна реализация
разреженного умножения с градиентами и измерения памяти. По размеру исходного
файла нельзя оценить стоимость обучения полного графа.

Текущие модели имеют искусственные вход, выход, правила пластичности и память.
Не называть их полной цифровой мухой, симуляцией её сознания, свободно говорящей
системой или универсальным программистом. Сохранять отрицательные результаты.

Все процессы, результаты которых включены в архив, завершены. Фонового обучения нет.
