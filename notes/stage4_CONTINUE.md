# Продолжение Drozofila-training после этапа 4

Основной репозиторий: https://github.com/oxura/Drozofila-training
Рабочие исходники, данные, веса, журналы и результаты хранить в этом репозитории.
Читайте STAGE4_RESULTS.md, results/stage4/summary.json и AGENTS.md.

## Состояние проекта

- Сохранены полные исходные данные и все четыре этапа исследования.
- Источник содержит 138639 нейронов; обучаемый фрагмент — 256 нейронов,
  7514 направленных связей, примерно 0,185% исходных нейронов.
- Этап 3 дал точную арифметику на длинных числах с явным регистром переноса
  и заданным обходом разрядов. Все 860 элементарных переходов были учебными.
- Этап 4 обучает движение указателя, запись конкретной цифры, NEXT и HALT.
  В режиме с историей в учебных трассах всего 140 различных наблюдений.
  Интерфейс и высокоуровневые операции ограничены; это не широкий интеллект.
- 36 подтверждающих запусков по 1200 шагов: варианты с внешней историей,
  внутренней памятью, обоими механизмами и без них; контрольные графы, MLP и GRU.
- Высокоуровневый план либо даёт пользователь, либо строит написанный нами BFS
  по выученной модели переходов. Сам алгоритм поиска не обучался.
- Правильность планов проверяется независимым функциональным эталоном;
  эталон и программа-свидетель не передаются планировщику.
- Короткая арифметика, память и шаблоны кода прежних этапов остаются отдельными
  моделями. Общий интерфейс не означает переноса знаний между ними.

## Запуск после клонирования

```bash
python restore_large_files.py
python fly_program.py --program 'разверни | чётные | +1' --data '1 2 3 4' --trace
python fly_program.py --data '1 2 3' --goal '4 3 2'
python smart_fly.py 'сложи 99999999999999999999 1' --verify
```

Зависимости — requirements.txt и README. Файл Connectivity_783.parquet
хранится в 97 частях assets/connectivity_783; скрипт проверяет их хэши и
восстанавливает точные 100804642 байта. Он не загружает данные из интернета.

## Воспроизведение и продолжение

```bash
python stage4_train.py --mode hidden --conditions fly --seeds 0 --steps 1200 --eval-every 300 --output results/stage4/reproduction
```

Для продолжения сначала скопируйте каталог запуска с last.pt и best.pt, затем
передайте копию в --resume и увеличьте общее число --steps. Скрипт восстановит
веса, оптимизатор и RNG. Cosine-расписание пересчитывается; это не идентично
непрерывному запуску с новым бюджетом с самого начала. Проверка 800->801 есть
в results/stage4/resume_verification.json.

Все финальные тесты этапов 1-4 уже открыты. Не подбирать по ним настройки и не
объявлять повторное измерение новой независимой оценкой. Для следующего опыта
нужен заранее выделенный протокол с другими семействами задач.

## Следующий содержательный шаг

1. Перейти от композиции шести знакомых операций к выведению нового правила
   из нескольких демонстраций. Удержать целые семейства правил вне обучения.
   Не путать новую длину с новым элементарным алгоритмом.
2. Учить высокоуровневую политику выбора программы; сравнить её с внешним BFS
   при одинаковом бюджете проверок. Сейчас BFS написан нами.
3. Добавить память с несколькими адресами и задачи исправления неверного
   действия. Нынешний выходной буфер только дополняется, undo нет.
4. Измерять забывание при последовательном освоении разных задач и перенос
   между навыками. Пока модули обучены раздельно.
5. Сопоставить несколько независимых фрагментов коннектома и обычные сети.
   Преимущество над обнулёнными рёбрами не равно превосходству над GRU.

Следующий агент должен прочитать конкретные метрики и отрицательные результаты,
а не исходить из предположения, что мозг мухи лучше обычной нейросети.
Все включённые в отчёт запуски завершены; фонового самообучения нет.
