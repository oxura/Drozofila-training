# FlyBrain Lab: третий этап — точная арифметика через выученные шаги

## Что получилось и что это означает

Добавлен отдельный арифметический модуль: сеть предсказывает цифру результата и следующий перенос/заём, а внешняя программа подаёт очередной разряд. Это позволяет повторять выученные элементарные переходы на длинных числах. Старые модели памяти и простых Python-шаблонов сохранены и доступны через общий интерфейс.

**Это искусственная обучаемая система на фрагменте коннектома, а не полная цифровая муха. Речь о проверенном арифметическом навыке; понимание свободного русского, универсальное программирование и интеллект уровня человека здесь не показаны.**

## Что обучалось, а что было написано нами

| Часть системы | Происхождение |
|---|---|
| 256 нейронов и 7514 направленных связей | Фрагмент настоящего коннектома v783 |
| Силы существующих связей | Обучаются в условиях fly/rewired, знак сохраняется |
| Входное преобразование, выходные классификаторы, динамика | Искусственные обучаемые параметры |
| Цифра результата и следующий перенос/заём | Предсказания обученной сети |
| Регистр переноса, выравнивание и порядок разрядов | Написанный нами интерфейс |
| Правильный перенос в учебном примере | Подсказка учителя при обучении |
| Остановка после ширины входа + один разряд | Заданное правило |
| Знак, сравнение модулей чисел, частичные произведения | Написанный нами механизм композиции |
| Русские команды и разбор выражений | Ограниченная программная грамматика |
| Ответ на код/повтори/разверни | Сохранённая нейросеть второго этапа |

Сеть получает тип операции, две цифры и перенос как 33 входных признака. Она делает четыре внутренних обновления на том же направленном графе и выдаёт два распределения по десяти классам: цифра и следующий перенос. Между позициями в дискретном варианте сохраняется только предсказанный перенос; прочее внутреннее состояние сбрасывается. Непрерывный вариант сохраняет 256 состояний и не получает правильный перенос.

Обучаемых параметров: 21 614 у коннектома, 21 020 у MLP, 14 100 у вариантов с фиксированными или отключёнными связями. MLP имеет два скрытых слоя по 120 элементов. Контроль без связей всё ещё содержит обучаемые входы, выходы и нелинейные элементы.

## Учебные данные и пределы обобщения

Полная таблица содержит **860 элементарных переходов**, и все они входят в обучение: 200 для сложения, 200 для вычитания и 460 достижимых состояний умножения на цифру. Это исчерпывающее обучение небольшому набору правил, а не независимый тест на этих 860 строках. Новые длинные примеры состоят из уже известных элементарных переходов.

Другой вариант получает 4800 коротких последовательностей с числами длины 2–4; они содержат 855 из этих 860 переходов, но их внутренние переносы не используются в функции потерь. Выбор модели использует 384 отдельные короткие задачи. Финальный набор: 960 задач (5 длин × 3 операции × 64 примера). Учебные, проверочные и финальные пары не пересекаются; перестановка операндов сложения тоже учитывается при разделении.

Дополнительно проверены 24 цепочки: много девяток плюс единица, длинный заём из степени десяти, равные операнды, умножение на ноль и на девять. Процент полностью правильных стрессовых ответов:

## Проверка, что вычисляет именно обученный модуль

В `stage3_engine.py` нет обращения к правильным ответам, к учебной таблице или вычислению суммы/разности/произведения целых операндов средствами Python. Oracle находится отдельно в генераторе данных и оценке. Обнуление весов превращает ответ на 123 + 456 в 0: готовый калькулятор не подменяет испорченную сеть.

Режим `--compiled` один раз получает предсказания сети для всех 3000 допустимых входных комбинаций интерфейса, включая недостижимые при правильном счёте состояния. Затем он использует эти предсказания как таблицу конечного автомата. Это ускорение сохранённой модели; ошибки сети в нём не исправляются. Обучающая таблица правильных ответов при этом не загружается. Для каждого дискретного checkpoint отдельно проверено совпадение прямого и табличного вывода на трёх 1000-значных задачах. Обычный запуск CLI по умолчанию использует прямой вывод.

На 32-значных задачах при принудительном обнулении переноса точность коннектома с регистром:

- Seed 0: 7.81% с обнулённым переносом; 4.17% при отключении обученных рёбер после обучения.
- Seed 1: 7.81% с обнулённым переносом; 4.17% при отключении обученных рёбер после обучения.
- Seed 2: 7.81% с обнулённым переносом; 0.00% при отключении обученных рёбер после обучения.

Падение после отключения связей означает зависимость конкретного обученного решения от них. Это не доказывает особой пригодности исходного коннектома: отдельно обученные модели с другими связями или без них дают самостоятельный контроль.

`--verify` проверяет простые команды обратной операцией и альтернативным порядком вычисления, также через нейросеть. Согласие проверок не является доказательством: согласованные ошибки возможны. Эти проверки не участвовали в подсчёте основной точности и не исправляли ответы.

## Как пользоваться

После установки зависимостей из README в каталоге проекта:

```bash
python smart_fly.py 'сложи 99999999999999999999 1' --verify
python smart_fly.py 'вычти 5 12'
python smart_fly.py '(12345+67890)*(73-12)' --compiled
python smart_fly.py 'умножь -123456789 37' --verify --json
python smart_fly.py 'код сложи u x'
python smart_fly.py 'повтори 1 2 3'
python smart_fly.py --interactive --compiled
```

Код, повторение и разворот обслуживает модель второго этапа, с прежними ограничениями: четыре шаблона функций и короткие последовательности. Новая арифметика не превратила её в универсального программиста. Интерактивный ввод не обновляет веса.

Для повторения отдельного запуска в новом каталоге:

```bash
python stage3_train.py --mode discrete --conditions fly --seeds 0 --steps 6000 --eval-every 500 --output results/stage3/reproduction
```

Для продолжения скопируйте каталог запуска, включая `last.pt` и `best.pt`, затем:

```bash
python stage3_train.py --resume results/stage3/reproduction/discrete_fly_seed0/last.pt --steps 8000
```

Восстанавливаются веса, AdamW и генераторы случайных чисел. При увеличении общего числа шагов cosine-расписание скорости пересчитывается; это не идентично непрерывному запуску с новым бюджетом с самого начала. Для дискретного варианта используются подсказки и цифры, и переноса, для непрерывного — только выходные цифры.

## Как двигаться к более широким способностям

Точный счёт — полезный компонент, но простые калькуляторы тоже превосходят человека в нём. Следующий научно полезный шаг — уменьшить объём заданного нами алгоритма и научить систему самой выбирать порядок действий. Увеличение числа нейронов без такого изменения не гарантирует прогресса.

1. **Выучить управление вычислением.** Давать вход и итог, постепенно убирать подсказки о переносе, направлении чтения и остановке. Проверять новые длины, основания счисления и незнакомые правила. Отдельно измерять, какие части процедуры были выучены.

2. **Память и планирование.** Добавить адресуемую память и обучаемые действия чтения/записи. Задачи: новое сочетание знакомых операций, сохранение промежуточных результатов, возврат после ошибки. Контроли должны получать ту же память и бюджет вычислений.

3. **Более содержательное программирование.** Перейти от четырёх шаблонов к выбору алгоритма, ветвлениям и циклам. Разделять учебные и финальные программы по структуре, проверять поведение на новых входах. Текущий разбор выражений написан нами и таким достижением не считается.

4. **Непрерывное обучение без забывания.** Последовательно добавлять новые семейства задач, хранить примеры прошлых навыков, измерять одновременно освоение нового и потерю старого. Сейчас арифметический и текстовый модули раздельны; совместное обучение не проведено.

5. **Проверить роль биологической структуры.** Повторить опыт на нескольких независимо выбранных фрагментах, с другими размерами, и сопоставимых обычных сетях. Масштабировать граф только после появления воспроизводимого выигрыша. Для полного графа потребуется разреженное вычисление; текущая реализация маленького графа использует плотное умножение.

Эти пункты — следующий исследовательский план, а не уже достигнутые способности. В этой сессии обучение и оценка завершены; фонового процесса самообучения нет.

## Источники и воспроизводимость

Исходный граф: [Drosophila_brain_model](https://github.com/philshiu/Drosophila_brain_model), commit `91bdd1e7dcf193f3e7ca5a8933497fcef63b7960`. Полные исходные файлы, лицензия, SHA-256 и предыдущие два этапа остаются в архиве. Всего источник содержит 138 639 нейронов; обучаемые 256 составляют около 0,185% этого числа.

Идея внешней памяти изучалась в [Neural Turing Machines](https://arxiv.org/abs/1410.5401). Обучение простым алгоритмам с интерфейсами-лентами и переносом на длинные числа исследуется в [Learning Simple Algorithms from Examples](https://arxiv.org/abs/1511.07275). Наш механизм проще: обход и промежуточные подсказки заданы явно. Эти статьи не доказывают эффективность коннектома или интеллект текущей модели.

Зафиксированный план: `results/stage3/confirmation/plan.json`; он содержит SHA-256 кода до открытия финального теста. Итоги: `results/stage3/summary.json`. Данные: `data/stage3/manifest.json`. Для каждого запуска сохранены веса, оптимизатор, журнал, предсказания, исчерпывающая точность по учебным переходам и сверка двух способов вывода. Трасса 1000-значного сложения: `results/stage3/confirmation/discrete_fly_seed0/thousand_digit_trace.json`.
